# Spine Shelf

A bookshelf for your library where every book is a spine. Group shelves by genre, stars, author, publisher, format, status, price, page count or spice. Dark and light themes. No backend, no account: your books are saved in your browser.

## Features
- Shelves you can regroup: pick a field, then a value, on each shelf
- Spines or covers view, with S / M / L sizes
- Stats: total, read %, reading now, want to read, average stars, top genre
- Add, edit and delete books; look up details and covers from Open Library
- Search by title or author
- Export and import your library as JSON
- Dark and light theme (follows your system by default)

## Run it
Open `index.html` in a browser. No build step.

## Host it free on GitHub Pages
1. Create a repo and push these files to `main`.
2. In **Settings → Pages**, set **Source** to **GitHub Actions**.
3. The included workflow publishes the site on every push.

## Notes
Data lives in `localStorage`, so it is per browser. Use Export to back it up or move it to another device.
